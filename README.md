## 🚀 What I've Been Building

- **AI medical scribe**: an event-driven platform that turns clinical conversations into structured notes, using GPU-based speech-to-text, speaker diarization, and LLM-generated output, with a Flutter mobile client.
- **RAG helpdesk chatbot**: a Claude-powered assistant over a company knowledge base with vector search and streaming responses, deflecting up to **50%** of support tickets.
- **Ticketing assistant widget**: drafts replies by searching closed cases and the knowledge base, cutting response time by **40%**.
- **Enterprise SSO platform**: full-stack single sign-on built on OAuth 2.0, OpenID Connect, and IdentityServer4, improving cross-app integration by **80-90%**.
- **Legacy modernization**: refactored older applications into **.NET 8** services, with large gains in performance and maintainability.
- **POS & inventory system** (freelance): Flutter + Firebase with real-time sync for orders and stock.
